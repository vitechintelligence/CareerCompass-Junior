# Approved visual direction

The Unit 1 proof follows the approved Career Compass Junior student design direction from the project review images.

## Student experience

- White + vivid blue premium young-learner UI
- Rounded cards, soft sky gradients, playful educational world illustration
- Student Home with greeting, progress, XP, next lesson and recent lessons
- My Journey / My Lessons as an illustrated winding 12-unit map, not a plain grid
- Interactive lesson pages with large bilingual headings, audio, activity cards, voice practice, reflection and completion celebration
- Embedded gamification: XP, badges and personal progress rather than public ranking
- Mobile-first layout that remains useful on tablet/desktop

## Interaction principles

- Tap targets remain large and obvious for ages 7–12
- START / GROW / STRETCH supports differentiation without ranking children
- Pronunciation follows Listen → Copy → Record → Replay → Try Again
- Student voice recordings are ephemeral and must not be uploaded or persisted
- No student email is required for standalone access

The visual direction should be preserved as the product grows; future screens should extend this system rather than introduce unrelated dashboard styles.
